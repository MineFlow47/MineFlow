# Résumé du Projet MineFlow

## 🎯 Objectif du Projet

MineFlow est une **solution de gestion logistique minière** conçue pour optimiser les opérations à Kolwezi. Ce projet répond à la question fondamentale : **"Comment crée un logiciel c'est quoi le début"** en fournissant une structure complète et une documentation détaillée.
