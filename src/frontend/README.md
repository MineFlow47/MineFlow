# Frontend

Ce dossier contiendra le code de l'interface utilisateur.

## Structure Suggérée

```
frontend/
├── public/           # Fichiers statiques
├── src/
│   ├── components/   # Composants réutilisables
│   ├── pages/        # Pages de l'application
│   ├── services/     # Services API
│   ├── store/        # Gestion d'état (Redux/Vuex)
│   ├── styles/       # Feuilles de style
│   ├── utils/        # Utilitaires
│   └── App.js        # Composant principal
├── tests/            # Tests frontend
└── package.json      # Dépendances
```

## À Faire

1. Choisir le framework (React, Vue, Angular, etc.)
2. Configurer le projet avec Create React App ou Vue CLI
3. Définir le design system
4. Créer les premiers composants
