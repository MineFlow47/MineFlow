# Code Partagé

Ce dossier contient le code partagé entre le frontend et le backend.

## Contenu Typique

- **Types/Interfaces** : Définitions TypeScript partagées
- **Constantes** : Valeurs constantes utilisées partout
- **Validateurs** : Fonctions de validation communes
- **Utilitaires** : Fonctions helper partagées

## Exemple de Structure

```
shared/
├── types/           # Types TypeScript
├── constants/       # Constantes
├── validators/      # Validateurs
└── utils/           # Utilitaires
```
