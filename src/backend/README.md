# Backend

Ce dossier contiendra le code du serveur (API, logique métier).

## Structure Suggérée

```
backend/
├── api/              # Endpoints API
├── models/           # Modèles de données
├── services/         # Logique métier
├── middleware/       # Middlewares (auth, validation)
├── utils/            # Utilitaires
├── config/           # Configuration
└── tests/            # Tests backend
```
