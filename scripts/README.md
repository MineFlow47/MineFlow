# Scripts

Ce dossier contient les scripts utilitaires pour le projet.

## Types de Scripts

### Scripts de Développement
- `setup.sh` - Configuration initiale du projet
- `dev.sh` - Lancer l'environnement de développement
- `clean.sh` - Nettoyer les fichiers temporaires

### Scripts de Déploiement
- `build.sh` - Construire l'application pour production
- `deploy.sh` - Déployer sur le serveur
- `backup.sh` - Sauvegarder la base de données

### Scripts de Maintenance
- `migrate.sh` - Exécuter les migrations de base de données
- `seed.sh` - Peupler la base de données avec des données de test
- `test.sh` - Exécuter tous les tests

## Utilisation

```bash
# Rendre un script exécutable
chmod +x scripts/nom_du_script.sh

# Exécuter un script
./scripts/nom_du_script.sh
```
